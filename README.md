# 📊 Desafio Power BI - DIO

Este repositório contém a entrega do **Desafio de Projeto da DIO - Criando Relatórios Interativos com Power BI**.  
O objetivo foi desenvolver um **dashboard interativo** baseado no conjunto de dados **Sample Financials**, aplicando conceitos de modelagem, design de relatórios e boas práticas de visualização.

---

## 🚀 Objetivo do Projeto
- Reproduzir (e aprimorar) um relatório prático em Power BI.  
- Utilizar botões de navegação para fornecer melhor **navegabilidade** entre páginas.  
- Criar segmentadores e interações dinâmicas para explorar os dados de forma flexível.  
- Publicar o relatório no **Power BI Service**, deixando-o acessível online.

---

## 🛠️ Tecnologias Utilizadas
- [Power BI Desktop](https://powerbi.microsoft.com/)  
- Dataset: **Sample Financials** (disponível [aqui](https://github.com/julianazanelatto/power_bi_analyst))  
- GitHub para versionamento e portfólio  

---

## 📌 Estrutura do Dashboard
✔️ Página 1:  
- Layout personalizado com objetos de design  
- Gráficos interativos sobre vendas, lucro e segmentos de clientes  
- Segmentadores e botões de navegação  

✔️ Página 2:  
- Visão complementar dos indicadores  
- Diferentes visuais sobre o mesmo assunto utilizando **indicadores e botões**  
- Análises comparativas e insights adicionais
